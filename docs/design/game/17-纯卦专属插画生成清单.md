## 3. 执行步骤（密钥到位后）

1. **生成**：`seedream-image` 逐张生成（不支持组图，8 张各自独立请求），保存到临时目录。
2. **去水印**：`watermark-removal` 对每张执行 OCR 检测 → 定位 → 迭代 inpaint → 双验证（AI 生成图入库前强制）。
3. **处理**：`game-icon-generation` —— PIL 白底转透明 / 居中裁剪 1:1 / 压缩至合理体积（参考现有 `hex_*.png` 尺寸规格，脚本见 `scripts/generate_hexagrams.py` 输出参数）。
4. **覆盖入库**：另存为 `public/hex_qian_qian.png` 等 8 个文件（**同名覆盖即自动生效**，`LoadingScene` 已注册全部 64 键）。
5. **验证**：
   - `npm run build` 全绿；
   - 开发态 `npm run dev` 打开，确认卜辞栏与商店卡传说档（乾为天等 8 张）显示新主视觉、无白底异常、缩放正确（`setScale` 按 `hexImg.width`，见 `BuciBarManager`/`ShopScene`）；
   - 视觉自查：§16.7.3 乾为天金框/篆印，其余 7 张风格统一。
