> 状态：待确认

## 一、设计概述

将现有「卜辞牌」（纯牌型系数加成的永久被动）整体替换为 **六十四卦** 系统。

核心规则（已与用户确认）：

1. **卜辞栏**：3 格，显示于 **战斗 / 地图 / 黄金台** 三个场景。
2. **全部一次性消耗**：主动使用会消耗；被动触发也会消耗。**没有永久被动、没有可重复主动**。
3. **同卦可购买多次**：同一卦买多张，堆叠在**同一格**（显示数量）。触发时同一卦**只触发第一张**（该格计数 -1，计数归零则移出栏）。
4. **出售**：卜辞栏内点击卦象露出「使用」「出售」小标签；**被动卦只有「出售」**。出售价 = 购买价一半（向下取整）。「出售」仅在**黄金台**可用；「使用」仅当处于黄金台，或战斗处于**主动技可发动阶段**。
5. **主动发动时机**：黄金台内，或战斗主动技阶段。
6. **分批**：按**上卦分组**（天/地/雷/风/水/火/山/泽 共 8 宫，每宫 8 卦 = 64）。**第一批 = 天宫 8 卦**（全部由用户给定，零设计风险），跑通整套系统后逐宫补齐。
7. **被动触发事件**：战斗失败扣天命、天命归零、战斗节点胜利、事件节点出选项、选择战斗节点、招募 120 通宝角色 等，后续可扩展。

---

## 二、第一批：天宫 8 卦（全为用户给定，无设计风险）

| 卦名 | 类型 | 价格 | 效果 | 触发 / 发动 |
|------|:----:|:----:|------|------------|
| 乾为天 | 主动 | 30 | 天命上限 +10，同时天命 +10 | 手动使用（黄金台 / 战斗主动阶段） |
| 天水讼 | 被动 | 30 | 抵挡一次战斗失败引起的天命扣减 | 战斗失败将扣天命时触发，抵消本次扣减 |
| 天泽履 | 被动 | 50 | 天命被扣减到 0 以下时，恢复到 1，避免游戏失败 | 天命将 ≤0 时触发，回复到 1 |
| 天地否 | 主动 | 30 | 扣减 50 点天命上限，恢复 20 点天命 | 手动使用 |
| 天火同人 | 被动 | 20 | 在战斗节点取得胜利则恢复 10 点天命 | 战斗节点胜利后触发 |
| 天雷无妄 | 被动 | 20 | 在「事件」节点需选择选项时，恢复 10 点天命，并随机为你选择一个 | 事件节点出选项时触发 |
| 天山遁 | 被动 | 30 | 选择「战斗」节点时，跳过战斗，增加 10 点天命 | 玩家选择战斗节点时触发 |
| 天风姤 | 主动 | 40 | 移除一张角色牌（自选），增加 10 点天命；无角色牌不得使用 | 手动使用 |

> 天宫 8 卦覆盖了：主动使用 ×3（乾/否/姤）、被动触发 ×5（讼/履/同人/无妄/遁），
> 涉及天命上限、天命增减、战斗失败、游戏失败挽救、战斗胜利、事件选择、跳战斗、移除人杰——
> 基本覆盖整套触发系统的所有分支，适合作为打通全链路的第一批。

## 三、数据模型

### 3.1 `BuCiCard` 重构（`src/models/RunState.ts`）

```ts
export type Trigram = '乾' | '坤' | '震' | '巽' | '坎' | '离' | '艮' | '兑';

export type BuCiType = 'active' | 'passive';

export interface BuCiCard {
  id: string;
  name: string;          // 卦名，如「乾为天」
  upper: Trigram;        // 上卦（用于分组 / 卦象图）
  lower: Trigram;        // 下卦
  price: number;
  type: BuCiType;
  desc: string;          // 效果描述文本（商店 / 栏位 tooltip）
  effect: BuCiEffect;    // 效果定义
  // 运行时
  count: number;         // 堆叠数量（同卦多张）
}
```

### 3.2 效果定义（判别联合，`BuCiEffect`）

```ts
export type BuCiEffect =
  | { kind: 'destiny_up'; maxInc: number; curInc: number }        // 乾为天
  | { kind: 'block_battle_lose_deduction' }                        // 天水讼
  | { kind: 'save_from_zero' }                                     // 天泽履
  | { kind: 'destinyMaxDown_curUp'; maxDown: number; curUp: number } // 天地否
  | { kind: 'destiny_up_on_battle_win'; amount: number }           // 天火同人
  | { kind: 'event_autopick'; amount: number }                     // 天雷无妄
  | { kind: 'skip_battle'; amount: number }                        // 天山遁
  | { kind: 'remove_character'; amount: number }                   // 天风姤
  // 后续批次新增：grant_seal_to_pool（坤为地 / 地水师）、牌型系数类等
```

被动效果统一带**触发条件**（见 §5 触发映射）。

### 3.3 卦象目录（`src/models/Shop.ts` 替代 `BUCI_CATALOG`）

- `BUCI_CATALOG` 替换为 `HEXAGRAM_CATALOG`（数据驱动，含 price + BuCiCard）。
- 现有 5 张「破军·×」卜辞牌**移除**（牌型系数功能由后续批次的特定卦象承接，不在本批次）。

## 四、卜辞栏 UI（跨三场景复用）

新增共享组件 `src/scenes/managers/BuciBarManager.ts`（参照 `CharacterBarManager` / `InfoBarManager` 模式）：

- **布局**：3 个槽位，横向排列。每格显示卦名（或卦象图缩略）+ 右上角**堆叠计数**。
- **点击交互**：点击某格露出「使用」「出售」小标签；**被动卦只显示「出售」**。出售标签旁显示出售价（= floor(price/2)）。
- **场景权限规则**：
  | 场景 | 使用（主动卦） | 出售 |
  |------|:--:|:--:|
  | 黄金台 ShopScene | ✅ | ✅ |
  | 战斗 GameScene | ✅ 仅主动技阶段 | ❌ |
  | 地图 MapScene | ❌（仅展示） | ❌ |
- **展示时机**：三场景常驻；战斗/地图为顶部信息栏旁的小横条，黄金台可放大。

## 五、被动触发系统

参照 `src/skills/` 事件总线模式，新增 `src/engine/BuciEffects.ts`（纯函数 + 事件钩子），在现有流程挂点：

| 触发事件 | 挂点位置 | 对应卦象 |
|---------|---------|---------|
| `on_battle_lose`（战斗失败、将扣天命） | `GameScene` / 战斗结算，扣天命前 | 天水讼（抵消本次扣减） |
| `on_destiny_would_zero`（天命将 ≤0） | 天命扣减结算后判断 | 天泽履（回 1，避免失败） |
| `on_battle_node_win`（战斗节点胜利后） | `MapScene` 结算胜利后 | 天火同人（+10 天命） |
| `on_event_node_choice`（事件节点出选项） | `MapScene` 事件弹窗弹出时 | 天雷无妄（+10 天命 + 随机选） |
| `on_node_select_battle`（玩家选择战斗节点） | `MapScene` 节点点击进入战斗前 | 天山遁（跳过战斗 +10 天命） |
| 手动 `active_use` | `BuciBarManager` 使用按钮 | 乾为天 / 天地否 / 天风姤 |

被动触发通用规则：命中触发条件时**只消耗该格第一张**（`count - 1`，归零移出栏）；触发后弹出卦象动画 + 效果反馈，随后消失。

**优先级**：多张被动卦同时可触发时，按栏位顺序（从左到右）依次结算。

## 六、主动发动

- **黄金台**：栏内任意主动卦可点「使用」，立即结算并消耗。
- **战斗主动技阶段**：复用现有 `ActiveSkillManager` 的「主动技可发动」时机判定，主动卦的「使用」仅在该阶段可用。
- 天风姤特殊校验：`roster` 为空时不可使用（使用按钮置灰 / 提示）。

1. **素材**：生成卦象图 → `public/hexagram_*.png`；`LoadingScene.loadAssets()` 注册。

7. **测试**：`RunState.test` / `Shop.test` 更新；新增 `BuciEffects.test`（各被动触发 + 主动使用 + 堆叠只扣第一张）。

9. **文档**：重写 `06-牌与道具系统.md` 6.2 章节为「卜辞栏（六十四卦）」；同步 `02-对战系统.md`、`主策划案.md`、`README.md` 索引（旧「破军·×」引用清除）。
