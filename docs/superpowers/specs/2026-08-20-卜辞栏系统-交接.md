## 一、设计规则（已锁定，勿改）

- 卜辞栏 **3 格**，显示于 **战斗 / 地图 / 黄金台** 三场景。
- **全部一次性消耗**：主动使用消耗；被动触发消耗。**无永久被动、无可重复主动**。
- **同卦可买多张** → 堆叠同一格（`count` 计数）；触发**只扣第一张**（count-1，归零移出栏）。
- 点击卦象露出「使用」「出售」小标签；**被动卦只有「出售」**；出售价 = 购买价一半（`floor(price/2)`）。
- 使用权限：**黄金台** 或 **战斗主动技可发动阶段**；**地图仅展示**（不可点击）。
- 出售权限：仅黄金台。
- 卦象分组：按**上卦**分 8 宫（天/地/雷/风/水/火/山/泽）每宫 8 卦 = 64。**第一批 = 天宫 8 卦**，其余批次后续再做。
- 旧「破军·×」牌型系数卜辞已**整体移除**；牌型系数功能由**后续批次**特定卦象承接，**不要**再加回 `coefficientBonus`。

## 四、剩余工作（reasonix 需完成）

### 4.1 MapScene（`src/scenes/MapScene.ts`）— feat(map)/feat(gameplay)

1. **卜辞栏（仅展示）**：接入 `BuciBarManager`，`context:'map'`，摆放在顶栏下方右侧（建议 `x = width-190, y = 150`）；`create()` 时 `refresh()`，并在 `refreshTopBar()` 后同步 `refresh()`。
2. **天山遁（跳过战斗）**：在 `enterNode()` 中，当节点是**战斗节点**（normal/elite/boss，非 shop/event）时，进入战斗前调用 `triggerSkipBattle(run)`。若非 null：弹提示「跳过战斗，天命+N」，然后按**胜利结算**推进（清节点/推进层数/加通宝/存档），**不进入战斗**。注意确认敌人生成逻辑不残留。
3. **天雷无妄（事件自动选择）**：在 `enterNode()` 事件分支，弹事件前调用 `triggerEventAutopick(run)`。若非 null：弹提示，并让 `MapEventModal` **自动随机选一个选项**（不走玩家点击）→ 建议给 `MapEventModal.open` 加 `autoPick?: boolean` 参数，或在 MapScene 里用 `randomEvent` + `applyEventChoice` 直接结算。处理好 `startBattle` 分流（伏兵）。
4. **天火同人（战斗节点胜利回天命）**：战斗胜利结算路径调用 `triggerDestinyUpOnBattleWin(run, nodeType)`（仅战斗节点触发），弹提示。可挂在 `RunManager.applyBattleResult` 胜利分支（模型层）或 `BattleFlowManager.showRunModeResult`（场景层，能弹提示更好），reasonix 自行选择并保证只触发一次、且只在战斗节点（normal/elite/boss）。

### 4.2 战斗失败 / 游戏失败（天水讼、天泽履）— feat(gameplay)

- **天水讼（抵挡战败扣天命）**：战败扣天命前调用 `triggerBlockBattleLose(run)`，若 true 则**本次不扣天命**。建议挂在 `RunManager.applyBattleResult` 战败分支 / `applyDefeat` 前。
- **天泽履（天命归零救回）**：天命被扣到 ≤0 时调用 `triggerSaveFromZero(run)` 回 1。建议在战败结算后 / `isRunOver` 判断处挂。至少要覆盖**战斗失败**这个主要归零路径。

### 4.3 GameScene 战斗卜辞栏 + 主动技阶段（`src/scenes/GameScene.ts`、`src/scenes/managers/ActiveSkillManager.ts`）— feat(scene)/feat(ui)
